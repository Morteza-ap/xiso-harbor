# Editorial interface and motion

Direction: a disc archive — precise, restrained and slightly cinematic. The
existing green extracted-files and monochrome GOD palettes remain. The animated ocean
is preserved at the user's request.

- Compact serif mode titles pair with the existing native sans interface and mono
  format labels. A centered disc engraving is the one signature graphic, rotating once every
  72 seconds without shifting between output formats.
- Mode choices use native radio controls and a quiet selected surface. Keyboard
  focus remains visible, including on older WebKit versions.
- Three shared regions group Output format, Games and Destination. Calm surfaces
  protect text from the animated background. Destination and folder name stack,
  with a resolved output path below and the primary action fixed at the bottom.
- Games appear once in a unified list with add/remove actions and scoped image
  validation status. Completed outputs retain their Finder actions.
- Help opens in a side sheet with its heading focused initially; keyboard users
  can Tab to the close button and use Escape. Explanatory text cannot be selected
  or dragged. Session diagnostics and its copy action remain available.
- Format guidance lives in the side sheet, keeping the format selector compact.
- Mode titles enter with a short, staggered fade and rise. The disc stays anchored;
  the green atmosphere fades over a black ground. Hover feedback stays small,
  buttons compress on press, and the primary arrow moves a few pixels on hover.
- CSS transitions name their properties. No layout dimensions are animated. Rapid
  mode changes cancel prior Web Animations. Reduced motion disables both the new
  animations and CSS/pseudo-element transitions; the existing canvas already
  observes that preference.

All assets and fonts stay local. Conversion and output safety checks are unchanged.
The native file picker can append games to an existing selection; completed
outputs must be reset before changing that selection.
